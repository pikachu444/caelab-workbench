# MDO Studio 화면 읽기

먼저 [실제 CalculiX MDO 가이드](01_end_to_end_calculix_mdo_guide.md)에서 입력과 계산을 준비합니다. 이전 문서의 GE·보 합성 화면을 실제 계산 결과처럼 소개한 캡션과 미구현 조작 안내는 철회했습니다.

| 화면 | 읽는 방법 |
|---|---|
| 연구 설정 | 덱의 명시적 토큰, 변수 범위와 단위, 출력 응답에 연결할 목적/제약을 확인합니다. 단위를 입력해도 솔버 수치가 자동 환산되지는 않습니다. |
| 설계점 표 | PENDING은 미계산, COMPLETED는 필수 응답을 읽은 계산, FAILED는 실행/응답 실패입니다. FEASIBLE은 선언한 수치 제약에 대한 판정입니다. |
| 파레토 | 현재 계산한 표본 중 비지배점입니다. 샘플 밖의 전역 최적해나 공학적 승인을 뜻하지 않습니다. |
| 반응 곡선 | GP의 예측 평균과 불확실성 띠입니다. 실제 FE 표본과 구분해서 읽습니다. 3D 회전 곡면이나 검증된 오차 한계가 아닙니다. |
| 민감도 | 표본의 Spearman 순위 상관입니다. Sobol 1차/총차 지수나 인과적 기여율이 아닙니다. 자료가 부족하면 순위를 만들지 않습니다. |
| 선택점 적용 | 성공한 해석점의 입력 출처를 확인하고 백업 후 INP에 치환합니다. 별도 CAD 파일은 바뀌지 않습니다. |

라이트/다크 테마는 표시 설정입니다. 테마 전환이나 예제 로드가 새 해석을 실행하지 않습니다. GE 목표 사양에는 실제 해석 결과나 임의 소요시간을 표시하지 않습니다.
