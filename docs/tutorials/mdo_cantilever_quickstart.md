# 이전 캔틸레버 안내 정정

이 문서의 이전 버전에는 완전하지 않은 덱 조각, 연결되지 않은 GUI 버튼, 실행 근거 없는 최적 수치가 포함돼 있었습니다. 해당 절차와 수치를 철회합니다.

[실제 CalculiX 덱으로 시작하는 MDO 가이드](01_end_to_end_calculix_mdo_guide.md)를 사용하세요. 전체 입력, 실제 버튼, 변수·응답의 단위, 계산·출처 확인, 원본 백업·적용과 저장·재열기를 함께 설명합니다.

INP 토큰 치환은 FreeCAD 형상 갱신이나 재메시가 아닙니다. 임의 캔틸레버의 형상·단면을 바꾸려면 그 입력에서 파라미터 변경이 물리적으로 올바른지 별도로 확인해야 합니다.
