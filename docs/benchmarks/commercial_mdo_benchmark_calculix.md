# GE 브래킷·로어 암 벤치마크 목표 사양

**Benchmark Target Specification — 향후 3D FEA 대규모 캠페인을 위한 저장소의 공식 목표 사양.** 여기서 ‘공식’은 이 저장소의 목표 문서라는 뜻이며 GE·Altair·Dassault가 승인한 비교 결과라는 뜻이 아닙니다. 실제 모델과 비교 문제의 확정은 아래 준비 조건을 충족한 뒤 이 문서를 갱신해 기록합니다.

## 현재 근거와 정정

2026-10-27 [감사](../review/2026-10-27-readme-benchmark-audit.md)에서 기존 GE 감량률·최대응력·실행시간, 상용 도구 비교값에 대응하는 입력·로그·출처를 확인하지 못했습니다. 해당 수치와 ‘검증 통과’, 속도 향상 비교표를 철회합니다. 미확인 결과를 정밀한 목표값으로 바꿔 유지하지 않습니다. GE 데모는 미계산 사양이며, 작은 튜토리얼 해석의 성공으로 이 벤치마크를 완료 처리하지 않습니다.

잘못 인용한 Altair 예제의 실제 제목은 다음과 같습니다. 둘 다 로어 컨트롤 암 최적화 수치의 근거가 아닙니다.

- [OS-T: 2000 — Design Concept for a Structural C-Clip](https://2023.help.altair.com/2023.1/hwsolvers/os/topics/solvers/os/design_reference_for_structural_c_clip_r.htm)
- [OS-E: 0105 — Nonlinear Analysis of Cantilever Beams with Follower Forces](https://help.altair.com/hwsolvers/os/topics/solvers/os/cantilever_beam_follower_forces_example_problem_intro_r.htm)

## 1. GE Jet Engine Bracket

[GE의 챌린지 소개](https://www.ge.com/news/reports/jet-engine-bracket-from-indonesia-wins-3d-printing)는 엔진 제조·정비 시 취급용 브래킷의 재설계 경연입니다. 그 경연의 위상·형상 재설계와 이 저장소의 유한 개수 치수변수 탐색은 같은 최적화 문제가 아닙니다. GE 기사 수치를 새로운 상용 비교값으로 사용하지 않습니다.

| 항목 | 목표 사양과 미확정 사항 |
|---|---|
| 원본 | 출처·사용권·개정·해시가 있는 CAD와 완전한 네이티브 입력 확보 필요 |
| 문제 구분 | 공식 챌린지 재현인지 자체 파라메트릭 파생 문제인지 명시 |
| 모델 | 3D 솔리드 브래킷. C3D10 후보이며 메시 규모는 실제 생성 후 기록 |
| 재료·단위 | Ti-6Al-4V 후보. 물성 출처·온도·단위계는 입력 확보 시 확정 |
| 하중·구속 | 인장·횡하중·비틀림 등 원 문제의 전체 케이스와 하중 전달 면을 확인 후 고정 |
| 설계변수 후보 | 베이스/리브/벽 두께, 필렛 반경, 보스 외경, 보강재 높이 |
| 목적·제약 | 질량 최소화와 응력·처짐·체결부 하중 제약. 수치와 허용오차는 결과를 보기 전에 확정 |

솔리드 모델의 필렛·보스 치수는 INP의 문자열 토큰만 바꿔 자동 재메시되지 않습니다. 네이티브 CAD 파라미터 갱신·재메시 또는 검증된 메시 변형 경로와 조건 영역 보존을 먼저 마련해야 합니다. UI의 미계산 예제 변수 범위는 이 과정이 구현됐다는 증거가 아닙니다.

## 2. Suspension Lower Control Arm

| 항목 | 목표 사양과 미확정 사항 |
|---|---|
| 원본 | 배포 가능한 CAD/메시·재료·조건을 가진 사례와 정확한 문헌 페이지 확보 필요 |
| 모델 | 솔리드 또는 셸 모델을 사례에 맞게 선택. 실제 절점/요소 수는 미측정 |
| 하중·구속 | 제동·선회·요철 하중 및 부싱/볼조인트 경계의 원자료 확인 필요 |
| 변수 후보 | 웹·플랜지 두께, 부싱 하우징·보스 치수. 각 변수의 물리 입력 변경 경로 검증 필요 |
| 목적·제약 | 질량과 강성·응력 등. 피로·고유진동수는 해당 해석·응답 경로 확보 후 추가 |

이 저장소에서 확인한 로어 암 상용 실행 결과는 없습니다. 종전 감량률·질량·절점 수·특정 튜토리얼과의 일치 주장은 철회합니다.

## 3. 비교 캠페인의 완료 조건

1. 입력 원본·라이선스·해시, 솔버 버전, 단위, 요소/재료, 모든 하중·구속·접촉을 고정합니다. baseline의 반력 평형·변위·응력·질량과 필요한 메시 수렴을 확인합니다.
2. 상용 도구와 동일한 목적·변수 영역·제약·하중 케이스·계산 예산을 사용합니다. 위상 최적화와 치수 최적화를 동일 문제로 비교하지 않습니다.
3. 응답별 출력 위치·절점 외삽/평균화·집합·프레임·단위를 고정합니다. FRD 절점 응력과 적분점 응력을 섞지 않습니다. `mm-N-s` 체계의 질량 단위를 kg로 임의 표기하지 않습니다.
4. 각 설계점의 실제 입력, 명령, 실행 ID, 원로그, 종료·판독 상태, 출력 해시와 측정 시간을 보존합니다. 실패·취소·재시도·캐시·검증 호출을 따로 집계합니다.
5. 대리모델은 실제 해석 표본에 적합하고 독립 검증점으로 오차를 평가합니다. 예측 후보는 네이티브 솔버로 다시 계산합니다. GP 불확실성 띠만으로 설계 안전성을 판단하지 않습니다.
6. 하드웨어·코어 수와 CAD/재메시/학습/최종 검증 포함 범위를 명시한 뒤 계산량과 시간을 비교합니다. 다른 사람이 동일 입력으로 재현해야 합니다.

현재 상태는 **목표 사양 정리·입력 및 비교 원자료 확보 전**입니다. 실제 입력부터 시작하는 작은 연결 사례는 [CalculiX MDO 튜토리얼](../tutorials/01_end_to_end_calculix_mdo_guide.md)을 사용합니다.
