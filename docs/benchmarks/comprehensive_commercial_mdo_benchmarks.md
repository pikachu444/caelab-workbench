# 다분야 산업 벤치마크 후보

이 문서는 향후 검증할 문제 후보 목록입니다. 상용 매뉴얼의 공인 문제·실측 성능표가 아닙니다. 2026-10-27 감사에 따라 근거가 연결되지 않은 정밀 메시 규모, 감량률, 최적 질량, 안전계수 달성값과 상용 예제 번호를 철회했습니다. 법규·설계기준을 만족했다는 주장도 하지 않습니다.

| 분야 | 후보 모델 | 확보·검증해야 할 입력과 응답 |
|---|---|---|
| 항공우주 | GE 엔진 브래킷 | 원본과 파생 문제 구분, 다축 하중, CAD 변경·메시, 질량·응력·처짐 |
| 자동차 섀시 | 로어 컨트롤 암 | 부싱/조인트 조건, 하중 이력, 질량·강성·응력 |
| 파워트레인 | 커넥팅 로드 | 접촉·교번 하중·재료 피로자료와 피로 평가 방법 |
| 기체 구조 | 컷아웃이 있는 날개 리브 | 셸 모델, 경계·하중, 좌굴 모드와 메시 수렴 |
| 충돌 안전 | 박판 크래시 박스 | 해당 명시적 솔버 연결, 소성·접촉·속도, 에너지 평형과 압궤 이력 |
| 압력용기 | 플랜지 노즐 | 내압·볼트·열경계, 접촉, 응력 선형화와 적용 설계기준 |
| 토목 | 박스 거더 | 지지·자중·활하중, 처짐·응력·좌굴 및 기준 적용 범위 |

GE 브래킷과 로어 암의 우선 목표 및 잘못된 Altair 출처 정정은 [Benchmark Target Specification](commercial_mdo_benchmark_calculix.md)에 모았습니다. 다른 후보도 출처·사용권 있는 입력을 확보하고 실제 실행·응답 판독·독립 재현을 확인하기 전에는 완료로 표시하지 않습니다.

제품의 현재 CalculiX 연결 범위를 다른 솔버·피로·충돌·법규 검증 전체로 확대하지 않습니다. 저장소의 단위 테스트나 작은 [MDO 튜토리얼](../tutorials/01_end_to_end_calculix_mdo_guide.md)은 이 산업 모델군의 성능 증거가 아닙니다.
