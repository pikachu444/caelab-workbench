# 검사와 재현

[루트 AGENTS.md](../AGENTS.md)의 실행·통합·보고 규칙을 적용한다. 제품 담당은 자신의 수정에 필요한 테스트 파일도 메인에게 배정받는다. 테스트 폴더 전체를 여러 작업자의 공동 편집 공간으로 취급하지 않는다.

- 결함을 재현하는 입력, 실제 실패 조건, 기대하는 사용자 동작을 검사한다. 구현을 그대로 흉내 내거나 같은 판독기를 두 번 호출한 일치만으로 정확성을 주장하지 않는다.
- 수치 검증은 해석해 또는 독립 기준과 허용 오차를 명시한다. 프로세스 모의·합성 검색 자료·Qt offscreen 검사를 실제 솔버·검색 품질·실화면 검증과 구분한다.
- 외부 실행 파일·자료가 없으면 해당 실환경 검사에 구체적인 skip 이유를 남긴다. 제품 코드의 누락·오류를 환경 부족으로 위장하지 않는다.
- 실패하는 검사를 통과시키려고 기대값·skip·xfail을 바꾸지 않는다. 의도된 동작이 바뀐 경우에는 요구사항 근거와 메인의 판단을 함께 남긴다.
- 외부 라이선스 자료와 대형 자산의 보관은 루트 규칙을 따른다. 파일·명령·출력 근거 없이 과거의 통과 수치를 현재 실행 결과로 보고하지 않는다.
