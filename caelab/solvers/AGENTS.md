# 솔버 실행·판독·보조 변환

[상위 AGENTS.md](../AGENTS.md)를 적용한다. 이 폴더는 솔버 담당 개발자가 맡으며, 실제 세션과 관련 테스트는 메인이 작업별로 배정한다.

- 솔버별 실행·결과 판독·설치 도우미와 명시적인 보조 변환을 담당한다. 네이티브 입력 본선과 보조 변환기의 범위는 DESIGN §6을 따른다.
- 보조 변환기의 지원표는 실제로 방출하는 입력 의미와 일치해야 한다. 네이티브 원 덱을 실행하기 위해 보조 모델로 재작성하거나 보조 지원표로 제한하지 않는다.
- 반력 등 검증 수치는 적용 하중·출력 요청·절점/집합 범위와 대조한다. 요청한 결과가 없으면 0이나 성공으로 채우지 않는다.
- FreeCAD 작성 덱의 과거 확인 사례에서는 FRD에 FORC가 없어 DAT의 NODE PRINT를 사용했다. 모든 덱에서 FORC가 없다고 가정하지 말고 실제 출력 블록과 요청을 확인한다.
- 새 솔버의 실제 실행 검사는 `tests/test_solver_smoke.py`의 기존 체계에 추가한다. 설치·외부 자료가 필요한 검사와 모의 검사를 구분하고, 테스트 파일 편집은 메인에게 함께 배정받는다.
