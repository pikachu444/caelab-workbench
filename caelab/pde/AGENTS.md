# PDE 계산

[상위 AGENTS.md](../AGENTS.md)를 적용한다. 이 폴더는 PDE 담당 개발자가 맡으며 실제 세션은 메인이 필요한 작업에만 배정한다.

- FEniCSx 기반 PDE 계산과 자체 입력 형식을 담당한다. 구조 FE 모델 스키마로 편입하지 않는다.
- 실행 환경 탐색과 작업·결과 전달은 상위 연결 계약을 따른다. 독립적인 작업 관리 체계를 추가하지 않는다.
- 수치 검증은 해석해가 알려진 문제의 오차·수렴 차수와 대조한다. 실제 FEniCSx 실행과 모의 검사를 구분한다.
- 제품 확장 시점은 DESIGN §12를 따른다. 기존 코드·유효한 검사를 보존하고 본선 연결과 무관한 예제 확대를 우선하지 않는다.
