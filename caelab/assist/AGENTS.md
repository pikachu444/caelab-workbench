# 결과 근거 토론·지식 검색

[상위 AGENTS.md](../AGENTS.md)를 적용한다. 이 폴더는 토론·지식 담당 개발자가 맡으며, GUI 패널의 변경은 GUI 담당과 메인이 조정한다.

- 선택 실행의 입력·로그·결과 요약·출처를 근거로 읽고 제안한다. 임의로 모델·덱·프로젝트를 변경하거나 계산을 시작하지 않는다. 제안 적용과 실행은 사용자 행동으로 분리한다.
- 솔버·단위·실행 출처·자료 부재·서비스 실패를 보존한다. 없는 수치를 만들거나 다른 실행의 결과를 현재 근거로 사용하지 않는다.
- 공급자 범위와 실제 토론 완료 조건은 DESIGN §10을 따른다. 설정·프로필 존재와 실제 실행 구현을 구분한다.
- 검색 평가의 자료·질문·근거 주석 절차는 [KNOWLEDGE_SOURCES.md](KNOWLEDGE_SOURCES.md)를 따른다. 인용 형식·검색 적중·답변의 공학적 타당성은 별도 검사다.
- 전문가 패널의 기존 파일 복구와 공급자 연결을 새 패널 개발로 대체하지 않는다. 복구 범위는 기존 개선 계획 P2를 따른다.
