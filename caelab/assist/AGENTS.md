# 결과 근거 토론·지식 검색

[상위 AGENTS.md](../AGENTS.md) 및 [루트 AGENTS.md](../../AGENTS.md)를 적용한다. 이 폴더는 토론·지식 담당 개발자가 맡으며, 독립 전문가 프로그램과의 데이터 계약은 GUI 담당과 메인이 조정한다.

## 1. 책임과 경계
- 선택 실행의 입력 파일, 실행 로그, 결과 요약, 출처 메타데이터를 근거로 읽고 공학적 제안을 생성한다.
- 임의로 사용자의 모델 파일, 해석 덱, 프로젝트 설정을 변경하거나 솔버 계산을 직접 시작하지 않는다.
- 제안의 수용·적용과 후속 실행은 항상 사용자의 명시적인 동작으로 분리한다.

## 2. 근거 보존과 투명성
- 솔버 종류, 단위계, 실행 출처, 참조 자료 부재, LLM 서비스 실패 상태를 투명하게 보존한다.
- 존재하지 않는 수치를 환각(Hallucination)으로 꾸며내거나 다른 실행의 결과를 현재 근거로 혼용하지 않는다.
- 검색 평가의 자료 인용, 질문, 근거 주석 절차는 [KNOWLEDGE_SOURCES.md](KNOWLEDGE_SOURCES.md)를 따른다.

## 3. 프로그램 분리 원칙
- 해석 실행 창이나 전처리기 내부에 전문가 채팅 패널을 종속 결합하지 않는다.
- 전문가는 독립 프로세스/창에서 선택된 실행의 근거 파일을 전달받아 읽고 대화한다.
- 모델 해석 창은 전문가 UI, AI 공급자, 외부 네트워크 연결 없이도 독립적으로 완결 동작해야 한다.
