# caelab 핵심 로직 운영 규칙

[루트 AGENTS.md](../AGENTS.md)의 공통 운영 규칙을 따른다. 하위 모듈은 이 파일의 경계와 해당 폴더의 AGENTS를 함께 적용한다.

## 1. 책임과 아키텍처 경계
- 담당 영역은 외부 프로그램 연결, 프로젝트 관리, 데이터 모델, 해석 작업 오케스트레이션, 결과 파싱, 토론 보조의 핵심 비즈니스 로직이다.
- 화면 UI 코드는 `apps/workbench_qt/`에 두며, `caelab` 코어 패키지 내에서는 Qt 및 PySide6 모듈을 일절 import하지 않는다.
- 외부 프로그램 탐색 및 명령 정의는 `connections.py`와 프로그램별 어댑터로 모으고, 프로세스 실행 소유는 `jobs.py`, 사용자 명령 진입점은 `workbench.py`로 모은다.

## 2. 환경 설정 및 계약 원칙
- 실행 파일 경로, 작업 디렉터리, 환경 변수는 명시적 사용자 설정과 연결 계약 객체에서 얻는다. 특정 머신의 로컬 절대 경로나 임의의 테스트 경로를 제품 코드에 하드코딩하지 않는다.
- 공통 인터페이스 계약(`connections.py`, `jobs.py`, `workbench.py` 등)의 변경은 메인 세션이 편집자와 통합 순서를 총괄 관리한다.
- 프로그램 발견(Found), 프로세스 정상 종료(Exited 0), 결과 파일 판독 성공(Parsed)의 상태를 단계별로 명확히 구분하여 상위 계층에 전달한다.
