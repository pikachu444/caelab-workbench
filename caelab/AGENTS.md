# caelab 핵심 로직

[루트 AGENTS.md](../AGENTS.md)의 공통 운영 규칙을 따른다. 하위 모듈은 이 파일의 경계와 자기 폴더의 AGENTS를 함께 적용한다.

- 담당 영역은 프로그램 연결·프로젝트·모델·작업·결과·토론의 핵심 로직이다. 화면 코드는 `apps/workbench_qt`에 두며 코어에서 GUI를 import하지 않는다.
- 외부 프로그램 탐색·실행 명령의 정의는 `connections.py`와 프로그램별 어댑터로 모으고 실행 소유는 `jobs.py`, 사용자 명령 입구는 `workbench.py`로 모은다. 현재 분리되지 않은 경로는 기존 개선 계획의 대상으로 다룬다.
- 실행 파일·작업 디렉터리·환경은 명시적 설정과 연결 계약에서 얻는다. 특정 컴퓨터의 절대 경로나 예제를 제품 실행 경로로 하드코딩하지 않는다.
- 공통 계약의 변경은 루트 규칙에 따라 메인이 편집자·영향받는 모듈·통합 순서를 정한다. 프로그램 발견, 프로세스 종료, 결과 판독 성공을 구분해 전달한다.
