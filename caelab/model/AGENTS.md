# 보조 구조 모델·저장 형식

[상위 AGENTS.md](../AGENTS.md)를 적용한다. 이 폴더의 스키마는 여러 모듈이 공유하므로 메인이 변경 계약과 편집자를 정한다.

- 기존 보조 변환·검사용 내부 모델과 그 저장/읽기를 담당한다. 네이티브 입력 전체를 이 모델로 변환하도록 강제하지 않는다.
- 프로젝트의 프로그램·파일·작업·토론 관계와 보조 FE 모델의 책임은 DESIGN §5에 따라 분리한다. PDE·재료점·외부 계산기의 입력을 이 스키마에 편입하지 않는다.
- 보조 모델의 스키마 버전은 정수 하나로 저장하고, 구버전은 읽을 때 마이그레이션한다. 실패는 해당 위치·이유를 알리고, 형식 변경으로 기존 데이터가 유실되거나 다른 의미로 읽히는지 검사한다.
- 스키마 변경 전에 영향받는 변환기·검사·저장·수치 연결을 메인에게 알리고, 해당 담당과 한 계약으로 통합한다.
