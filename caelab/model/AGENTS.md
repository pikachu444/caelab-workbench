# caelab/model 규칙

- 기존 보조 변환·검사용 내부 모델 스키마와 그 저장/재개를 담당한다. 네이티브 입력 전체를 이 모델로 변환하도록 강제하지 않는다. 프로젝트의 프로그램·파일·작업·토론 관계는 DESIGN §5의 별도 책임이다. 여러 모듈이 함께 쓰는 공유 영역이라, 스키마 변경은 통합 채팅(000) 확인을 먼저 받는다.
- 스키마 버전은 정수 1개. 구버전 파일은 읽을 때 자동 마이그레이션하고, 실패하면 해당 섹션을 가리키는 오류를 낸다.
- PDE·재료점·외부 계산기는 이 스키마에 넣지 않는다 (설계 결정).
