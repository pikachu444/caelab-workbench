# 수치 엔진·최적화

[상위 AGENTS.md](../AGENTS.md)를 적용한다. 이 폴더는 수치 담당 개발자가 맡는다. 최적화 GUI는 GUI 담당 영역이며 별도로 배정받은 범위만 수정한다.

- 이 패키지는 2026-10-26 후속 사용자 지시에 따라 폐기 완료되었다. 모든 수치 엔진·최적화·대리모델 기능은 `caelab/mdo/`로 전면 교체되었으며, 이 폴더에는 신규 코드를 추가하지 않는다.
- 기존 수치 코드의 대체 사양 및 운영 규칙은 `caelab/mdo/AGENTS.md`를 따른다. 새 네이티브 연결은 INP 바인딩(`TemplateDeck`)과 StudyManager 경로를 사용한다.
- 실패·취소·부분 실패를 유효한 수치 후보로 바꾸지 않는다. 평가자의 실행 소유와 모델 변경 경계는 상위 핵심 로직 계약을 따른다.
- 제품 확장 순서와 최적화 화면의 사용자 미결정 사항은 DESIGN §11.5·§12를 따른다. 당장 필요한 결함 수정과 기능 확대를 구분한다.
- 해석해·허용 오차·독립 재평가로 계산 의미를 검사하고, 사용한 라이브러리 기능과 선언한 최소 지원 버전을 일치시킨다.
