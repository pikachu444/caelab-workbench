# caelab/numerical 규칙

- 소유: 002_수치 엔진·최적화 채팅.
- DOE·적합·최적화·UQ·민감도 수치 엔진. 원본 저장소(autonomous-cae-lab)의 동작을 유지하면서 이식한다.
- 기존 caelab/model 변수·응답 연결은 보조 경로로 보존한다. 모든 연구 입력을 이 스키마로 일반화하지 않는다. 제품 확장은 DESIGN §12의 4단계이며, 1단계 본선 연결을 먼저 닫는다. 최적화 화면 허용 범위는 사용자 결정 전까지 확대하지 않는다. 스키마 변경이 필요하면 직접 고치지 말고 병합 요청으로 올린다.
