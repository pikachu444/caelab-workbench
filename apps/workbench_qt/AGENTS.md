# Qt 화면과 사용자 동작

[루트 AGENTS.md](../../AGENTS.md)를 적용한다. 이 폴더의 화면은 GUI 담당 개발자가 맡으며, 토론·수치 담당이 패널을 수정할 때도 메인이 파일별 편집자를 먼저 정한다.

## 1. 화면 구조와 경계
- 화면 구조와 자체 창의 경계는 DESIGN §11을 따른다. 기존 메뉴·트리·도킹·아이콘을 일관되게 사용하며, 불필요한 전용 프로그램 기능의 복제를 지양한다.
- 화면은 Workbench 서비스의 상태와 실제 파일·실행 결과를 충실히 표시한다. 설치됨·입력 준비·실행 종료·결과 유효를 명확히 구분한다.
- 전처리 및 정밀 후처리의 전문 편집 동작은 전용 외부 프로그램(FreeCAD, ParaView 등)으로 연결한다. GUI 내부에 독자적인 솔버 변환이나 중복 프로세스 관리 경로를 두지 않는다.

## 2. 모듈 분리 및 독립 실행
- 해석 작업 창은 전문가 UI, AI 공급자, 외부 네트워크 없이 완전히 독립 동작한다.
- 전문가 프로그램은 독립 창(`expert_window.py`)으로 구동하며, 해석 창의 모듈 전환으로 대체하지 않는다.
- 다분야 최적화 및 파라메트릭 탐색은 독립 프로그램 MDO Studio([`apps/workbench_qt/mdo_studio/`](mdo_studio/))를 통해 제공된다. 부모 메뉴는 Workbench를 통해 독립 프로세스에 프로젝트·노드·스터디 파일 참조를 전달하며, 상세 개발 규칙은 하위 [`apps/workbench_qt/mdo_studio/AGENTS.md`](mdo_studio/AGENTS.md)를 따른다.

## 3. 검증 및 테마 원칙
- 모든 화면은 라이트 및 다크 테마([`theme.py`](theme.py))에서 텍스트 대비와 뷰포트 가독성을 보장해야 한다.
- 변경한 사용자 흐름은 실제 UI 화면에서 확인하며, 헤드리스 CI를 위한 Qt offscreen 테스트를 함께 작성한다.
