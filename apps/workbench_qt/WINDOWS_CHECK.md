# Windows 실화면 확인 — 절차와 목록

이 문서는 Windows PC에서 직접 해야 하는 확인입니다.
리눅스 가상 화면(Xvfb) 확인은 그 아래 단계이며, 이 확인을 대신하지 않습니다.
이 목록을 다 통과하기 전에는 GUI를 완료라고 하지 않습니다.

## 1. 준비 (Windows PC에서)

필요한 것:

- Windows 10/11 PC, 화면 배율과 해상도를 적은 뒤 시작합니다.
- Python 3.11 이상 (python.org 설치본, 설치 시 "Add python.exe to PATH" 선택).
- 이 저장소 폴더 전체 (git clone 또는 파일 복사).
- 있으면 함께 확인할 외부 프로그램: FreeCAD, ParaView, Gmsh, CalculiX(ccx).
  없으면 없는 대로 확인합니다 — 상자가 "찾지 못함"이라고 뜨는지도 확인 항목입니다.

## 2. 실행

방법 A (간단): 저장소 폴더에서 `apps\workbench_qt\run_workbench.bat` 더블클릭.
처음 한 번은 가상환경(.venv)을 만들고 PySide6·numpy·vtk를 설치하므로 몇 분 걸립니다.

방법 B (직접):

```bat
cd caelab-workbench
py -3 -m venv .venv
.venv\Scripts\python -m pip install PySide6 numpy vtk pytest
.venv\Scripts\python -m apps.workbench_qt
```

외부 프로그램 경로를 직접 지정할 때 (선택):

```bat
set CAELAB_FREECAD=C:\Program Files\FreeCAD 1.1\bin\FreeCAD.exe
set CAELAB_CCX=C:\calculix\ccx.exe
set CAELAB_PARAVIEW=C:\Program Files\ParaView\bin\paraview.exe
.venv\Scripts\python -m apps.workbench_qt
```

## 3. 증거 캡처

```bat
.venv\Scripts\python apps\workbench_qt\capture_windows.py
```

`windows_check_out\` 폴더에 프로젝트 화면·해석 창 그림과 상태 텍스트가 생깁니다.
단, 3D 화면(VTK)은 그림 캡처에서 검게 나올 수 있습니다 — 캡처 방식의 한계이며
실제 화면이 검은 것과 다릅니다. 3D 항목은 실제 화면을 눈으로 보고,
필요하면 Windows 캡처 도구(Win+Shift+S)로 따로 찍어 주세요.

## 4. 확인 목록

### 시작·공통

- [ ] 오류 창 없이 프로젝트 화면이 뜬다.
- [ ] 한글 글자가 깨지지 않고 네모(□)로 나오지 않는다.
- [ ] 배율 100%와 PC 기본 배율(125% 등) 양쪽에서 글자가 잘리지 않는다.
- [ ] 창을 1100×700 정도로 줄여도 "도식 맞춤" 버튼으로 상자 5개가 다 보인다.

### 프로젝트 화면 (런처)

- [ ] 상자 5개(형상·메시·구조 해석·결과·전문가 논의)와 연결선이 겹치거나 꼬이지 않는다.
- [ ] 결과→전문가 논의 연결선이 아래 방향으로 자연스럽게 이어진다.
- [ ] 각 상자의 상태 색과 글자가 서로 모순되지 않는다
      (예: 초록 "최신"인데 "프로그램을 찾지 못함"이면 실패).
- [ ] 설치 안 한 프로그램의 상자는 "찾지 못함"으로 표시된다.
- [ ] 도구상자에서 같은 항목을 두 번 더블클릭해도 상자가 중복으로 생기지 않는다.
- [ ] 형상 상자 더블클릭 → FreeCAD가 실제로 열린다 (설치된 경우).
- [ ] 결과 상자 더블클릭 → ParaView가 실제로 열린다 (설치된 경우).
- [ ] 구조 해석 상자 더블클릭 → 해석 창이 열린다.
- [ ] "전체 실행" 후 해석 상자에 최대 변위가 표시되고 결과 상자가 "최신"이 된다
      (CalculiX가 있을 때만).

### 해석 창

- [ ] 왼쪽 모델 트리와 오른쪽 속성 칸이 잘리지 않는다.
      특히 탄성계수 값과 단위(GPa)가 다 보인다.
- [ ] 트리에서 재료·하중·구속을 고르면 속성 칸이 그 항목으로 바뀐다.
- [ ] 속성 칸에 직접 고치는 입력 칸이 없고, 아래에 전용 프로그램에서
      고치라는 안내가 보인다 (이 화면은 확인 전용).
- [ ] 전문가 토론에서 제안을 적용하면 값이 바뀌고, 저장한 뒤 다시
      열어도 바뀐 값이 남아 있다.
- [ ] 입력 검사: 멀쩡한 모델은 "검사 통과", 재료를 없는 이름으로 바꾸면
      오류 한 줄이 뜨고 "고칠 위치로 이동"이 해당 단면을 선택한다.
- [ ] 3D 화면에 메시가 실제로 보인다 (캡처가 아니라 눈으로 확인).
      등각·정면·위 버튼과 화면 맞춤이 동작한다.
- [ ] 실행 후 3D 화면이 변형 형상과 색상 범례로 바뀐다.
- [ ] 아래 흐름 표시(열기→검사→실행→결과…)가 단계에 맞게 바뀐다.

### 되돌려 줄 것

- [ ] `windows_check_out\` 폴더 전체 (그림 + 상태 텍스트).
- [ ] 위 목록에서 실패한 항목 번호와, 실패 당시 화면 캡처.
- [ ] Windows 버전, 해상도, 배율, 설치된 외부 프로그램 목록.
